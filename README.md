# CloudScripts 🚀
用强大的 Shell 脚本轻松管理你的 Linode 实例

## 功能特性
### 账号与计费
- 🔍 API 连通性检测
- 👤 账户信息获取并持久化
- 🏷️ 添加优惠码

### 实例管理
- 🧱 创建实例（支持批量/单个）
- 🗑️ 删除实例
- ♻️ 重装实例
- 🔄 重启实例
- 🔐 重置实例密码
- 📈 实例配置升级
- 🧭 查看账户下实例的详细信息
- 🌐 根据 IP 搜索实例（自动切换至对应账号）

## 环境要求 📦
- 说明：脚本强依赖 `jq`，请先确保系统已安装。安装方式可参考你的发行版包管理器（如 `apt`, `yum`, `brew` 等）。

## 快速开始 ⚡
1. 克隆仓库
   ```bash
   git clone https://github.com/Coinsinical/CloudScripts.git
   ```
2. 运行脚本
   ```bash
   cd CloudScripts && bash linode.sh <token>
   ```
